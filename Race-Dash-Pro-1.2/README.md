## 📖 Описание

**RACE DASH PRO** — это профессиональная цифровая приборная панель для спортивных и тюнингованных автомобилей, построенная на Raspberry Pi 4.

Проект объединяет современный интерфейс в стиле, высокую скорость работы, поддержку различных ECU, расширенную телеметрию, запись логов, GPS-функции и физическую светодиодную индикацию оборотов двигателя.

### 🎯 Основная цель

Создать полностью самостоятельный продукт с собственным фирменным стилем, не копируя существующие решения, но с уровнем качества профессиональных приборных панелей.

## ✨ Возможности

### 🚗 Главный экран

| Параметр | Описание |
|----------|----------|
| **RPM** | Цифровой тахометр с сегментной дугой и градиентом |
| **Speed** | Крупные цифры скорости в центре |
| **Gear** | Отображение текущей передачи ([N], [1st], [2nd]...) |
| **Boost** | Индикатор давления наддува |
| **Coolant** | Вертикальный термометр температуры ОЖ |
| **Oil Temp** | Вертикальный термометр температуры масла |
| **Oil Press** | Вертикальный индикатор давления масла |
| **Lap Time** | Таймер сессии |

### 🎨 Профессиональный дизайн

- **Dark Carbon Fiber** — глубокий матовый карбон с циановыми акцентами
- **Стекло над углепластиком** — глянцевый эффект поверхности
- **Пульсация красной зоны** — последние 15% дуги RPM мигают ярко-красным
- **Моноширинные шрифты** — цифры не "прыгают" при изменении значений
- **Сглаживание (Anti-aliasing)** — все элементы выглядят гладко и профессионально

### 📱 Экран графиков

- Плотная сетка с едва заметными серыми линиями
- Толщина кривых: 2.5–3 пикселя
- Прозрачность линий: 85%
- Цветовая маркировка:
  - Обороты — белый
  - Скорость — циан
  - G-сенсор — оранжевый
- Отображение пиковых значений текущей сессии

### 📄 Экран логов

- Интерфейс терминала 
- Жёлтый цвет для системных ошибок
- Мигающий красный для критических ошибок
- Фильтр по уровням (INFO, WARNING, CRITICAL)

### 🎮 Управление

- Свайпы между экранами с инерцией и плавным затуханием
- Горячие клавиши:
  - `D` — Демо-режим
  - `R` — Сброс пика
  - `L` — Логи
  - `G` — Графики
  - `F` — Полноэкранный режим
  - `ESC` — Выход

### 💡 RGB-лента

- Поддержка WS2812/SK6812
- 29 светодиодов на GPIO 18
- Тест ленты при запуске (бегущий огонёк)
- Плавное зажигание по одному светодиоду
- Автоматическое выключение при завершении программы
